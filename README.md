# إهداء — موقع إهداءات رقمية تفاعلية

كل زبون له **رابط خاص ودائم** مثل: `https://موقعك/?g=sara-x7k2`
الإهداء نفسه ملف واحد: `gifts/sara-x7k2.json`. ما دام الملف موجود، الرابط شغّال.

## أنواع الكروت

| النوع | الوصف |
|---|---|
| `love` | «تحبيني؟» — زر «لا» يصغر ويهرب، ثم مركز هدايا (صور بولارويد، أغنية مع أسطوانة، رسالة بحركة الكتابة، فيديو) |
| `daily` | رسالة كل يوم — رسالة يوم 8 لا تنفتح إلا يوم 8 |
| `secret` | إهداء برقم سري — المحتوى **مشفّر فعليًا** (AES-GCM) ولا يُقرأ بدون كلمة السر حتى من ملف JSON |
| `arrow` | سهم الحب — بالون قلب، سهم يفرقعه، تهنئة وردية بوميض ذهبي، ثم شجرة تزهر بشكل قلب وتتساقط أوراقها |
| `namesong` | أغنية باسمك — حفلة متحركة، موسيقى تُصنع في المتصفح بلحن عيد الميلاد، والاسم يُنطق في مكانه (تسجيلك / ملف صوتي / نطق تلقائي عربي) |
| `gifts` | مركز الهدايا مباشرة بدون سؤال |
| `letter` | رسالة واحدة فقط |

## تجربة محليًا

انقر مرتين على `تشغيل-محلي.bat` (يحتاج Python مثبّت) ثم افتح:

- الموقع: <http://localhost:8765/>
- النماذج: `?g=demo-love` · `?g=demo-daily` · `?g=demo-secret` (الرقم السري 1234) · `?g=demo-arrow` · `?g=demo-namesong`
- لوحة الإنشاء: <http://localhost:8765/admin/>

> لا يشتغل الموقع بفتح `index.html` مباشرة من المجلد (لأنه يحمّل ملفات JSON). لازم خادم، حتى لو محلي.

## طريقة إضافة زبون جديد

1. افتح `admin/` وامْلأ البيانات واختر نوع الكرت.
2. اضغط **معاينة** لتشوف النتيجة قبل الحفظ.
3. اضغط **تحميل ملف JSON** واحفظه داخل مجلد `gifts/` بنفس الاسم.
4. الصور تُرفع من الجهاز مباشرة داخل اللوحة (زر «رفع صورة»)، وتُضغط وتُحفظ داخل ملف JSON نفسه، فلا تحتاج مجلد صور. (يبقى خيار كتابة رابط إن أردت.)
5. انشر التغييرات (أدناه). الرابط ورمز QR يظهران في اللوحة.

## النشر مجانًا على GitHub Pages (مرة واحدة)

1. أنشئ حسابًا على GitHub ومستودعًا جديدًا (Public) باسم مثل `ihda`.
2. ارفع محتوى هذا المجلد كاملًا (بواسطة GitHub Desktop أو السحب والإفلات في صفحة المستودع).
3. من إعدادات المستودع → **Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
4. بعد دقيقة يصير موقعك على: `https://<اسمك>.github.io/ihda/`
5. اكتب هذا الرابط في حقل «رابط موقعك المنشور» في اللوحة (يُحفظ تلقائيًا).

كل زبون جديد = ترفع ملف JSON (وصوره) للمستودع فقط. الروابط القديمة لا تتأثر أبدًا.

> بديل: Netlify Drop / Cloudflare Pages بنفس الفكرة (مجلد ثابت). أو أي استضافة مشتركة برفع الملفات عبر FTP.

## هيكل الملفات

```
index.html            ← صفحة عرض الإهداء (تقرأ ?g=المعرّف)
admin/index.html      ← لوحة إنشاء الإهداءات (للمالك فقط)
gifts/*.json          ← ملف لكل زبون
gifts/media/<id>/     ← صور/صوتيات كل زبون
css/styles.css        ← نظام التصميم (5 ثيمات: pink, lilac, sky, mint, cream)
assets/fonts/         ← خط الرسائل Noto Sans Arabic (woff2 مُجزّأ من مجلد «خطوط»)
js/app.js             ← المحمّل والموزّع
js/flows/love.js      ← كرت تحبني؟
js/flows/hub.js       ← مركز الهدايا وشاشات الصور/الأغنية/الرسالة/الفيديو
js/flows/daily.js     ← كرت رسالة كل يوم
js/flows/secret.js    ← كرت الرقم السري
js/flows/arrow.js     ← كرت سهم الحب (كانفس)
js/flows/namesong.js  ← كرت أغنية باسمك (Web Audio + كانفس)
js/crypto.js          ← التشفير (Web Crypto)
```

## الشخصية (الملصق)

- لكل إهداء: ارفع ملصقًا من اللوحة (حقل «صورة الشخصية»)، PNG شفاف أو GIF متحرك.
- بعد «نعم» في كرت تحبني؟ تظهر القطة المتحركة `assets/yes-cat.gif` تلقائيًا (أو صورة تحددها من حقل «صورة بعد نعم»).
- لكل الموقع: ضع الملف في `assets/` (مثل `assets/sticker.gif`) واكتب مساره في `index.html` داخل `<meta name="default-sticker" content="assets/sticker.gif">`. يُستخدم لكل إهداء لم يُحدَّد له ملصق.

## نطق الاسم في «أغنية باسمك»

بالترتيب حسب الجودة:
1. **تسجيلك**: في اللوحة زر «سجّل نطق الاسم» — قل «يا سارة!» بحماس خلال ثانيتين. يُحفظ داخل ملف الإهداء (WAV) ويشتغل على كل الأجهزة.
2. **ملف صوتي**: ارفع mp3/wav لاسم مسجّل أو مولّد بأي خدمة نطق.
3. **تلقائي**: بدون تسجيل يستخدم المتصفح صوت العربية المدمج في جهاز المستلم (آيفون: ممتاز، أندرويد: حسب الجهاز). اكتب الاسم بالتشكيل في حقل «الاسم كما يُنطق» لنطق أدق (مثل: هِبَة).

## ملاحظات مهمة

- **الرقم السري**: يُشفَّر المحتوى في اللوحة قبل الحفظ. إذا نسيت كلمة السر ما يمكن استرجاع المحتوى؛ احتفظ بها مع بيانات الزبون.
- **رسالة كل يوم**: يعتمد على تاريخ جهاز المستلم. من يغيّر تاريخ جهازه يقدر يفتح مبكرًا؛ هذا مقبول لهدية، وليس نظام حماية.
- **لوحة الإنشاء** لا تحفظ شيئًا على الخادم؛ هي أداة محلية تولّد الملف فقط. يمكنك حتى حذف مجلد `admin/` من النسخة المنشورة إن أردت.
- المعرّف المولّد يحتوي على جزء عشوائي حتى لا يخمّن أحد رابط زبون آخر.
