# إهداء — موقع إهداءات رقمية تفاعلية

كل زبون له **رابط خاص ودائم** مثل: `https://gift.wesal-shop.com/?g=sara-x7k2`
الإهداء نفسه ملف واحد: `gifts/sara-x7k2.json`. ما دام الملف موجود، الرابط شغّال.

## أنواع الكروت

| النوع | الوصف |
|---|---|
| `love` | «تحبيني؟» — زر «لا» يصغر ويهرب، ثم مركز هدايا (صور بولارويد، أغنية مع أسطوانة، رسالة بحركة الكتابة، فيديو) |
| `daily` | رسالة كل يوم — رسالة يوم 8 لا تنفتح إلا يوم 8 |
| `secret` | إهداء برقم سري — المحتوى **مشفّر فعليًا** (AES-GCM) ولا يُقرأ بدون كلمة السر حتى من ملف JSON |
| `arrow` | سهم الحب — بالون قلب، سهم يفرقعه، تهنئة وردية بوميض ذهبي، ثم شجرة تزهر بشكل قلب وتتساقط أوراقها |
| `namesong` | أغنية باسمك — حفلة متحركة، موسيقى تُصنع في المتصفح بلحن عيد الميلاد، والاسم يُنطق في مكانه (تسجيلك / ملف صوتي / نطق تلقائي عربي) |
| `gifts` | مركز الهدايا مباشرة بدون سؤال |
| `letter` | رسالة واحدة فقط |

## تجربة محليًا

انقر مرتين على `تشغيل-محلي.bat` (يحتاج Python مثبّت) ثم افتح:

- محليًا: <http://localhost:8765/>
- النماذج: `?g=demo-love` · `?g=demo-daily` · `?g=demo-secret` (الرقم السري 1234) · `?g=demo-arrow` · `?g=demo-namesong`
- لوحة الإنشاء: <http://localhost:8765/admin/> (لا تُنشر على الإنترنت)

> لا يشتغل الموقع بفتح `index.html` مباشرة من المجلد (لأنه يحمّل ملفات JSON). لازم خادم، حتى لو محلي.

## طريقة إضافة زبون جديد

1. شغّل `تشغيل-محلي.bat` وافتح <http://localhost:8765/admin/> ثم امْلأ البيانات واختر نوع الكرت.
2. اضغط **معاينة** لتشوف النتيجة قبل الحفظ.
3. اضغط **تحميل ملف JSON** واحفظه داخل مجلد `gifts/` بنفس الاسم.
4. الصور تُرفع من الجهاز مباشرة داخل اللوحة (زر «رفع صورة»)، وتُضغط وتُحفظ داخل ملف JSON نفسه، فلا تحتاج مجلد صور. (يبقى خيار كتابة رابط إن أردت.)
5. انشر التغييرات (أدناه). الرابط ورمز QR يظهران في اللوحة.

## الموقع منشور ويعمل

| البند | القيمة |
|---|---|
| رابط الموقع | <https://gift.wesal-shop.com> |
| رابط زبون | `https://gift.wesal-shop.com/?g=<المعرّف>` |
| لوحة الإنشاء | محلية فقط: <http://localhost:8765/admin/> بعد تشغيل `تشغيل-محلي.bat` |
| المستودع | <https://github.com/ihda-sa/ihda> |
| الرابط الاحتياطي | <https://ihda-sa.github.io/ihda/> |

الدومين `gift.wesal-shop.com` نطاق فرعي من دومين متجر سلة، مربوط بسجل CNAME إلى `ihda-sa.github.io`.
متجر سلة على `wesal-shop.com` لم يتأثر إطلاقًا.

## إضافة زبون جديد على الموقع المنشور

بعد ما تحمّل ملف JSON من اللوحة، ارفعه للمستودع بأمر واحد من مجلد المشروع:

```bash
git add gifts && git commit -m "زبون جديد" && git push
```

خلال دقيقة يصير رابط الزبون شغّالًا. الروابط القديمة لا تتأثر أبدًا.

أو من الويب: افتح <https://github.com/ihda-sa/ihda/upload/main/gifts> واسحب الملف وأفلته ثم اضغط Commit changes.

## هيكل الملفات

```
index.html            ← صفحة عرض الإهداء (تقرأ ?g=المعرّف)

gifts/*.json          ← ملف لكل زبون
gifts/media/<id>/     ← صور/صوتيات كل زبون

assets/fonts/         ← خط الرسائل Noto Sans Arabic (woff2 مُجزّأ من مجلد «خطوط»)
js/app.js             ← المحمّل والموزّع
js/flows/love.js      ← كرت تحبني؟
js/flows/hub.js       ← مركز الهدايا وشاشات الصور/الأغنية/الرسالة/الفيديو
js/flows/daily.js     ← كرت رسالة كل يوم
js/flows/secret.js    ← كرت الرقم السري
js/flows/arrow.js     ← كرت سهم الحب (كانفس)
js/flows/namesong.js  ← كرت أغنية باسمك (Web Audio + كانفس)
js/crypto.js          ← التشفير (Web Crypto)
```

## الشخصية (الملصق)

- لكل إهداء: ارفع ملصقًا من اللوحة (حقل «صورة الشخصية»)، PNG شفاف أو GIF متحرك.
- بعد «نعم» في كرت تحبني؟ تظهر القطة المتحركة `assets/yes-cat.gif` تلقائيًا (أو صورة تحددها من حقل «صورة بعد نعم»).
- لكل الموقع: ضع الملف في `assets/` (مثل `assets/sticker.gif`) واكتب مساره في `index.html` داخل `<meta name="default-sticker" content="assets/sticker.gif">`. يُستخدم لكل إهداء لم يُحدَّد له ملصق.

## نطق الاسم في «أغنية باسمك»

بالترتيب حسب الجودة:
1. **تسجيلك**: في اللوحة زر «سجّل نطق الاسم» — قل «يا سارة!» بحماس خلال ثانيتين. يُحفظ داخل ملف الإهداء (WAV) ويشتغل على كل الأجهزة.
2. **ملف صوتي**: ارفع mp3/wav لاسم مسجّل أو مولّد بأي خدمة نطق.
3. **تلقائي**: بدون تسجيل يستخدم المتصفح صوت العربية المدمج في جهاز المستلم (آيفون: ممتاز، أندرويد: حسب الجهاز). اكتب الاسم بالتشكيل في حقل «الاسم كما يُنطق» لنطق أدق (مثل: هِبَة).

## ملاحظات مهمة

- **الرقم السري**: يُشفَّر المحتوى في اللوحة قبل الحفظ. إذا نسيت كلمة السر ما يمكن استرجاع المحتوى؛ احتفظ بها مع بيانات الزبون.
- **رسالة كل يوم**: يعتمد على تاريخ جهاز المستلم. من يغيّر تاريخ جهازه يقدر يفتح مبكرًا؛ هذا مقبول لهدية، وليس نظام حماية.
- **لوحة الإنشاء خاصة بك وحدك.** مجلد `admin/` وملفاته مستثناة من الرفع في `.gitignore`،
  فهي غير موجودة على الإنترنت إطلاقًا ولا يقدر أحد يفتحها. تعمل على جهازك فقط عبر `تشغيل-محلي.bat`.
  ملفاتها محفوظة في سجل Git السابق، فيمكن استرجاعها لو حُذفت من الجهاز.
- المعرّف المولّد يحتوي على جزء عشوائي حتى لا يخمّن أحد رابط زبون آخر.

## الأمان — كيف تُحمى بيانات الزبائن

**كل إهداء يُشفَّر بالكامل قبل رفعه.** الملف الموجود في `gifts/` لا يحتوي إلا على
`{enc, iv, ct}` — لا اسم مستلم، ولا اسم مرسل، ولا نص رسالة، ولا نوع الكرت. حتى اسم
الملف معرّف عشوائي لا يدل على أحد.

مفتاح الفتح (256 بت عشوائي) موجود في **الرابط فقط** بعد علامة `#`:

```
https://gift.wesal-shop.com/?g=fxfybn929sgm#k=1MSIROnLv4BnAQ8hQWqoKDKSTIIirTuEOa5ZnxUrYTY
```

المتصفحات **لا ترسل ما بعد `#` إلى أي خادم إطلاقًا**. يعني المفتاح لا يمر على GitHub،
ولا على سلة، ولا في سجلات الاستضافة، ولا في معاينة الرابط على واتساب.

### ما الذي يحميه هذا فعليًا

| الاحتمال | النتيجة |
|---|---|
| أحد تصفّح المستودع على GitHub | يرى نصًا مشفّرًا فقط |
| تسريب المستودع كاملًا | لا شيء مقروء |
| موظف في GitHub أو سلة | لا يستطيع القراءة |
| محرك بحث فهرس الرابط بدون `#` | لا يستطيع القراءة |
| أحد جرّب تخمين المعرّفات | لا يستطيع القراءة بلا مفتاح |
| معاينة الرابط في واتساب | تظهر صورة عامة فقط، بلا محتوى |
| أحد عدّل ملف الإهداء | يُرفض الفتح (AES-GCM يكشف التلاعب) |

### ما لا يحميه

من يحصل على **الرابط الكامل** يقرأ المحتوى. هذا أصل الفكرة: الرابط هو المفتاح.
فمسؤوليتك أن ترسله للزبون في قناة خاصة، ومسؤولية الزبون ألا ينشره.

### قواعد التشغيل

1. **الرابط لا يُسترجع.** إذا ضاع، ضاع المحتوى ولا يمكن فكه. اللوحة تحفظ سجل الروابط
   في متصفحك، ونزّله من زر «تنزيل السجل» واحتفظ به **خارج مجلد المشروع**.
2. **لا ترفع سجل الروابط للمستودع أبدًا.** ملف `.gitignore` يمنعه، لكن انتبه.
3. **رسائل الرفع محايدة.** لا تكتب اسم الزبون في رسالة الـ commit؛ استخدم «زبون جديد».
4. النماذج `demo-*` غير مشفّرة عمدًا لأنها بيانات وهمية معروضة في الصفحة الرئيسية.

## طبقة حماية إضافية اختيارية

التشفير أعلاه كافٍ وحده. لو أردت طبقة ثانية (إخفاء حتى عدد الإهداءات وأوقاتها):

| الخيار | التكلفة | ماذا يضيف |
|---|---|---|
| GitHub Pro أو Team | 4 دولار/شهر | يسمح بنشر Pages من مستودع **خاص**، فلا يتصفح أحد المجلد أصلًا |
| Cloudflare Pages | مجاني | نفس الأثر مع مستودع خاص على GitHub المجاني، لكن يحتاج حساب Cloudflare |

في الحالتين يبقى التشفير هو خط الدفاع الأول، والمستودع الخاص خط ثانٍ.
